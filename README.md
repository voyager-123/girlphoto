# GirlPhoto

本地照片调色实验项目：先收集风格、质量和偏好标注，再训练评价模型与调色参数模型。

**标注工具和双模型训练流程已跑通，目前只有合成演示权重，尚未验证真实人像调色效果。**

## 已完成

| 模块 | 能做什么 |
| --- | --- |
| 标注网页 | 导入照片、多标签风格判断、质量三档评分、同图版本比较、撤销及 CSV/JSON 导出 |
| 模型 1 | 分别预测风格、质量与可选强度；结合原图和目标风格学习版本偏好 |
| 模型 2 | 输入原图、风格和强度，预测曝光、对比度、冷暖、色调、饱和度、暗部六项参数 |
| 调色与训练 | 可求导的全局调色引擎；支持监督训练、冻结模型 1 的反馈训练、权重保存与预测导出 |
| 数据工具 | 标注导出转换、缺失标签屏蔽、分组划分检查、合成演示及训练格式示例 |

模型使用 PyTorch 小型卷积网络，默认 CPU。参数属于本项目引擎，不直接对应 Lightroom 滑块。
标注网页与模型命令行目前分开运行，尚未提供网页自动调色按钮。

## 快速开始（Windows）

已验证 Python 3.12。两个环境相互独立，不向主 Python 环境安装依赖。

**标注照片：** 双击 `start.bat`；首次缺少依赖时先运行 `setup.bat`，会创建 `.venv`。
浏览器打开 <http://127.0.0.1:8765>。详细操作见 [标注说明](ANNOTATION.md)。

**运行两个模型：** 在项目目录依次执行：

```powershell
.\setup_models.bat
.\models.bat demo --out ml_runs\my-first-demo
```

安装脚本创建或复用 `.venv-models`，已经激活该环境也可以运行。
如安装需要代理，给 `setup_models.bat` 追加自己的 HTTP 代理地址。
演示会训练两个模型，并生成权重、指标、`preview.png` 和 `preview.parameters.json`。
再次实验请换一个输出目录。真实数据格式、训练与预测命令见 [模型说明](MODELS.md)。
